## Technical Details

### Grid Layout
- Icons display in a scrollable `GridView`
- Each icon is 50x50 pixels
- Font size: 28px (readable and clear)
- Max height: 180px (fits ~12 icons vertically)
- Maintains selection state when dialog opens
